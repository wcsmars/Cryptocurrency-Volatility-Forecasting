# Source data

The analysis uses [Kaushik Suresh's Kaggle dataset](https://www.kaggle.com/datasets/kaushiksuresh147/top-10-cryptocurrencies-historical-dataset).
Despite the URL's `top-10` wording, the downloaded ZIP contains 98 historical price CSVs and one static leaderboard. The downloaded observations span 18 July 2010 to 23 August 2022; some assets stop earlier. These are historical data, not current prices.

Run `python scripts/download_data.py` from the repository root. `raw/` is kept out of Git; `source_manifest.json` records the exact ZIP and per-file SHA-256 hashes. The script verifies both and refuses to overwrite existing CSVs. If Kaggle changes the archive, it fails visibly instead of silently changing the published experiment. An already downloaded matching ZIP can be supplied with `--zip /path/to/archive.zip`.

`sample/` holds eight major-asset CSVs (Bitcoin, Ethereum, BNB, XRP, Cardano, Solana, Dogecoin and Litecoin) copied unchanged from the source, so the pipeline runs without a download. Their hashes match `source_manifest.json`. The uploader publishes the dataset on Kaggle under CC0 (public domain) and says the prices were collected by web scraping and with Python packages such as investpy, a Yahoo Finance client and pandas-datareader.

Date labels are treated as calendar days and must be ISO 8601 (`YYYY-MM-DD`); a file using any other layout, such as day-first dates, is rejected instead of being reordered. The source description mentions multiple collection tools; the files do not establish consistent exchange close times or volume units. All supplied Currency labels are USD, but this does not establish that every Volume value is USD turnover. Volume is therefore summarized in source-reported units, and charts normalize it within each asset. It is not pooled or used as a cross-asset model feature. The static leaderboard is excluded from modeling and is not used to reconstruct historical membership.

Missing dates, zero/nonfinite prices and malformed candles are audited in the outputs. In `data_validation.csv`, `missing_days` counts inserted calendar gaps, while `invalid_close_rows`, `missing_or_invalid_volume_rows` and `ohlc_invalid_rows` count source rows; `missing_columns` lists optional columns absent from a file, whose counters are then left blank. No prices are interpolated, forward-filled, or fetched from a different source. Asset labels and market identity remain vendor-provided; this analysis cannot independently certify them. Missing daily prices invalidate every dependent return, feature and target. Zero volume remains an observed zero, with its frequency reported separately.
